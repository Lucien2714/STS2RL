# Step 2-k：从 boss run 的平台期继续训练，以及冻结策略的对照（`runs/step2k-plateau`、`runs/step2k-frozen`）

*2026-10-05*

## 做了什么

按指示从 boss run 的平台期重新开始：

- `runs/step2k-plateau`：`--init-from runs/step2h-boss/checkpoints/update_000192.pt --init-optimizer`（Step 2-j 加的，带上 Adam 的矩，避免新优化器把策略推走），全部战斗 MCTS-50，带 Giant 的评估修复，`--target-kl 0.02`，7 个模拟器。
- 第一个 seed 周期里，和 boss run 第 3–5 周期的同一批 seed 相比**低了约 1.5 层（p = 0.01–0.05）**，死在第 9 层之前的比例 17% 对 12%。

## 查原因

| 可能的原因 | 结果 |
|---|---|
| Giant 修复影响了别的战斗 | 不会：只有 Waterfall Giant 会出现 max HP ≥ 100,000,000 |
| 搜索设置、时间限制 | 相同，训练没有时间限制（`MctsConfig.seconds` 为 None） |
| 模拟器变了 | 没有：10-05 03:02 编译之后没有改动 |
| 学习率、Adam 步数 | 相同：3e-4，每次更新 6–7 步就因 KL 提前停止 |
| 停止时测到的 KL | **不同**：中位数 0.134，boss run 0.047，step2j 0.043 |

停止时的 KL 大约是 3 倍，看起来像是更新太大。但直接测量策略的变化（人类录像界面上相隔 6 次更新的 checkpoint 之间的 KL）和 boss run 末期差不多；从起点到第 18 次更新，地图 0.055、选牌 0.077、营火 0.099，变化不大。两种测量不一致，所以加一个对照。

### 冻结策略的对照（`runs/step2k-frozen`）

同一个起点、同样的 seed、搜索和评估，学习率 1e-12（策略实际上不变），4 个模拟器，150 局。

| | 局 | 平均 floor | 第 9 层前死亡 | 到第 17 层 |
|---|---|---|---|---|
| step2k-plateau（训练） | 184 | 18.3 | 17% | — |
| step2k-frozen（冻结） | 150 | 18.1 | 23% | 94 |
| 两者同一批 150 个 seed | | 18.33 对 18.09 | | |

- 冻结和训练在同一批 seed 上**没有显著差别**（46 个 seed 冻结更高、60 个更低，p = 0.21）。所以**下降不是 PPO 更新造成的**。
- 冻结策略对 boss run 第 3–5 周期同样低 1.3 层（p = 0.02）。**起点 checkpoint 本身就只有约 18.1–18.3 层**；boss run 第 3–5 周期的平均包含了它更早、更好的阶段（各周期 20.0、18.8、19.5），作为基线偏高。
- 结论：**以后比较用同一个 checkpoint 的冻结对照，不用"上一个 run 的某几个周期"**。

### 训练本身

在平台期继续训练 150 局，没有超过冻结的策略。按指示在约 182 局（`update_000049`）停止，空出 CPU 给评估修复的 A/B（Step 2-l）。

## 第 1 幕 boss 之前死掉的 run

按问题"第一层 boss 都没到的是什么情况"统计了 723 局（boss run 加 step2k）：

- **207 局（29%）死在第 17 层之前**；61% 死在精英战，39% 死在普通战斗。死亡集中在第 6–8 层和第 11–15 层，也就是遇到精英的楼层。
- 普通战斗的死亡多是消耗：进战斗时 HP 只有 37%（活下来的战斗平均 84%）。
- **一个精英造成了三分之一的早期死亡**：

| 第 1 幕精英 | 战斗 | 死亡 | 死亡率 | 进入时 HP |

| **Phrog Parasite** | 86 | 70 | **81%** | 82% |

| Byrdonis | 59 | 7 | 12% | 79% |
